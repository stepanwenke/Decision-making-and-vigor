## How to run it

#### 1. Simulate the data based on the mean and variance of the estimated parameters

1. Open *effort_simulate_data_recoverability.m*.
2. Specify variable *day* for session 1 or 2
3. Specify variable *model* (constrained_quadratic, constrained linear, unconstrained linear)
4. Run it to create a simulated data for 1000 synthetic subjects
5. Open *fit_physical_effort_ite.m* and specify the session (day) and model that you want to fit
6. Running the script will fit the synthetic data on the model and save the output to the
respective session (day1 or day2) and the respective model folder in the /output_fit subfolder. Histograms of
the fitted parameters will be stored there.

#### 2. Plotting fitted vs observed parameters

6. Open *plotting_recoverability.m*, define the session and the model and run it.
7. The plots are saved in the models' respective folder

#### 3. Plotting the choices generated by the simulated data

8. Open *plotting.m* and specify session (day), model and set *real* to **false**. Run it.

#### 4. Plotting the simulated vs real data

9. Open *effort_simulate_from_real_params.m* and set the session (day) and
the model
10. Run it. It will create a synthetic data created from the estimated parameters in the /output_sim subfolder
11. Open *plotting.m*. Specify the session (day), model and set *real* to **true**. Run it
