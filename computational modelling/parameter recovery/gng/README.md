## How to run it

#### 1. Simulate the data based on the mean and variance of the estimated parameters

1. Open *gng_simulate_data_recoverability.m*.
2. Specify variable *day* for session 1 or 2
3. Run it to create a simulated data for 1000 synthetic subjects
4. Open *fit_GNG_ite.m* and specify the session (day).
5. Running the script will fit the synthetic data on the model and save the output to the
respective session (day1 or day2) in the /output_fit subfolder. Histograms of
the fitted parameters will be stored there.

#### 2. Plotting fitted vs observed parameters and the choices generated by the simulated data

6. Open *plotting_recoverability.m*, define the session and run it.
7. The plots are saved in the models' respective folder

#### 4. Plotting the choices of simulated vs real data

9. Open *gng_simulate_from_real_params.m* and set the session (day).
10. Run it. It will create a synthetic data created from the estimated parameters in the /output_sim subfolder
11. Open *plotting.m*. Specify the session (day). Run it
