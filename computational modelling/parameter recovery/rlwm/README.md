## How to run it

#### 1. Simulate the data based on the mean and variance of the estimated parameters


1. First we will calculate the proportion of the estimated WM capacities in our data and use the same proportion for
the simulated data. Open *calc_K_distribution.K*, specify the model (ll_rlwm or ll_wmh) and specify session (day).
2.  Open *rlwm_simulate_data_recoverability.m*. Specify variable *day* for session 1 or 2 and *model* ll_rlwm or ll_wmh.
3. Run it to create a simulated data for 1000 synthetic subjects
4. Open *recover_find_K_wm.m* and specify the session (day) and the model (ll_rlwm or ll_wmh). This will estimate the WM capacity for each synthetic subject.
5. Open *recover_fit_RLWM_ite.m*. Specify the session (day) and the model (ll_rlwm or ll_wmh). Running the script will fit the synthetic data on the model and save the output to the respective session (day1 or day2) in the /output_fit subfolder. Histograms of the fitted parameters will be stored there.

#### 2. Plotting fitted vs observed parameters

6. Open *plotting_recoverability.m*, define the session and the model and run it.
7. The plots are saved in the */day* and */models*' respective folder

#### 3. Plotting the choices generated by the simulated data

8. Open *plotting_rlwm.m* and specify session (day), model. Run it.

#### 4. Plotting the choices of simulated vs real data

9. Open *RLWM_simulate_from_real_params.m* and set the session (day) and
the model
10. Run it. It will create a synthetic data created from the estimated parameters in the */output_sim* subfolder
11. Open *plotting_real_sim.m*. Specify the session (day), model. Run it
